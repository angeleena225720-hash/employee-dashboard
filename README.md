# Employee Dashboard

React (Vite) app with React Router and Bootstrap.

## Features
- Navbar with **Home** and **Employee Form** links
- Home (`/`) – employee dashboard table (id, name, email) fetched from https://jsonplaceholder.typicode.com/users
- Employee Form (`/employee-form`) – Name, Designation, Location, Salary with validation (no data is posted)

## Run locally
```bash
npm install
npm run dev
```
Build for production: `npm run build`
